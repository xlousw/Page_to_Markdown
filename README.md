# 页面转 Markdown（Page to Markdown）

一个 Chrome / Edge 浏览器扩展，将当前标签页中已渲染的正文保存为 Markdown。

## 设计原则

- 不进行任何爬取（no crawling）
- 不请求源代码、不追链
- 不上传任何内容到外部服务
- 只读取当前标签页**已加载的 DOM**

## 功能

- 识别标题、段落、列表、任务列表、引用、代码块、表格、图片、链接、删除线、高亮、上下标等常见结构。
- **可编辑预览**：提取后先在弹窗里预览，可直接修改再复制 / 下载。
- **仅保存选中内容**：先在页面上选中一段文字，再勾选后保存。
- **YAML Front Matter** 与 **文件名附加日期**。
- **文件名模板**：可用 `{title}`、`{host}`、`{date}` 占位符。
- **右键菜单**：在页面或选区上右键，一键「保存为 Markdown / 复制 Markdown」。
- **快捷键**（默认，可在 `chrome://extensions/shortcuts` 修改）：
  - `Ctrl+Shift+M`（macOS `⌘⇧M`）保存当前页面
  - `Ctrl+Shift+Y`（macOS `⌘⇧Y`）复制当前页面 Markdown
- **虚拟滚动预滚**：自动滚动页面及内部可滚动容器，让富文本编辑器、Notion、掘金等虚拟列表把正文渲染出来后再提取，最后滚回原位置。
- **尾巴清洗**：自动剔除「版权声明、请扫码关注、一键三连、相关推荐、侧栏目录、Cookie 弹窗」等非正文段落。

## 安装

1. 打开 `chrome://extensions/` 或 `edge://extensions/`。
2. 打开「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录。

## 使用

- 点击工具栏图标打开弹窗；或在页面任意位置右键；或直接按快捷键。
- 面板按钮：
  - **预览**：先提取并在下方文本框里展示，可直接编辑。
  - **复制**：复制当前预览（或未预览时自动提取一次）到剪贴板。
  - **下载 Markdown**：按文件名模板保存 `.md` 文件。

## 备注

- 对于复杂富文本编辑器，建议先手动选中正文并勾选「仅保存选中内容」，得到的结果最稳定。
- 所有选项（含文件名模板）会保存在浏览器本地存储里，下次打开自动恢复。
- 完全本地运行，不会向任何服务器发送请求。
